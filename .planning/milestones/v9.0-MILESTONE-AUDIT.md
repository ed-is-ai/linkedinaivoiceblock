## Findings

### ✅ RESOLVED during audit — Phase 28 "Last run" footer

`src/dashboard/evals.tsx:88` previously read `const lastRun = runs.at(-1) ?? null;`. `getEvalRuns()` returns the array **newest-first** (`evalRunStore.ts:83`), so `.at(-1)` was the **oldest** run, making the "Last run:" footer stale once ≥2 runs were persisted.

- **Fix applied:** `runs.at(-1)` → `runs[0]`. Committed **fc92b40**; `tsc --noEmit` clean.
- **Severity:** WARNING — display blurb only; never affected eval correctness, metrics, persistence, or labeling.

No outstanding milestone blockers.
