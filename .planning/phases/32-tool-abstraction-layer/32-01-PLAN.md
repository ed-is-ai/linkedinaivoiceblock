## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service worker → Anthropic API | Outbound network `fetch` carrying the user's API key; this code relocates into the tool's `execute()` but the boundary is unchanged |
| Anthropic API → service worker | Untrusted LLM JSON response parsed into selector strings |
| chrome.storage.local → tool | API key read from storage inside `execute()` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-32-01 | Tampering | LLM-proposed selector strings parsed in execute() | mitigate | `isRederiveModelOutput` type-guard relocates VERBATIM and still validates schema before any candidate is returned; acceptance criteria assert its presence + the schema-failure test path |
| T-32-02 | Information Disclosure | API key read from chrome.storage inside execute() | mitigate | No new logging added during relocation; key is never passed to the caller or written to traces — only `usage` and error message surface (preserved pattern). Acceptance: tool file references key only for the fetch Authorization header |
| T-32-03 | Information Disclosure | New shared-module import surface (tool imports from src/shared) | accept | Tool imports only TYPES (`Tool`, `AnthropicUsage`); no runtime secret crosses the new boundary. Zero-behavior-change: no new data exposure introduced |
| T-32-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this phase (RESEARCH §Package Legitimacy Audit: zero new deps); no install task to gate |
