## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chrome.storage.local → exported file on disk | User-controlled telemetry (trace entries) is serialized and written to a downloaded file. The traces already exclude API keys by schema (T-24-01). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Information Disclosure | `buildTracesExport` envelope written to disk | accept | TraceEntry has no apiKey field by construction (T-24-01); systemPrompt/userPrompt are the extension's own prompts + post text the user already opted to store. Export is a deliberate user action (button click). No new disclosure surface introduced beyond the existing Export JSON button. |
| T-25-02 | Tampering | `setTraces((result.llbTraces ?? []))` cast | mitigate | `result.llbTraces ?? []` defaults to an empty array when the key is absent/undefined; the export builder treats `traces: []` as valid (D-07), so a missing/corrupt key cannot crash the dashboard render or produce an invalid envelope. |
| T-25-SC | Tampering | npm installs | mitigate | This plan installs no new packages (no `npm install`). No supply-chain surface; the `tsx` devDependency is added in Plan 02 with its own gate. |
</threat_model>
