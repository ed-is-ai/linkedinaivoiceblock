<objective>
Add a `npm run trace-summary <file>` Node CLI (TypeScript via `tsx`) that reads a trace export JSON, prints a per-source/model cost-breakdown table to stdout (TRACE-05), and idempotently writes/updates a `## LLM Cost Reference` section in `README.md` (TRACE-06).

Purpose: Turns the exported trace store (Plan 01 output) into a human-readable cost report and keeps the README's cost documentation reflecting a real run. Costs are recomputed from stored token splits against current code prices so the README always shows today's rates.

Output:
- `scripts/trace-summary.ts` — validation, cost recompute via the shared `computeCostUsd`, grouped table, README section management.
- `package.json` — `"trace-summary"` script + `tsx` devDependency.
- `README.md` — created if missing; its `## LLM Cost Reference` section reflects the run.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-supplied file path → script | `process.argv[2]` is an arbitrary path the script reads. |
| untrusted JSON content → script | The export file may be malformed, oversized, or hand-edited; its `model`/`source` strings flow into table cells and map keys. |
| script → README.md on disk | The script overwrites a section of a file that may contain unrelated user-authored content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-03 | Denial of Service | `readFileSync` + `JSON.parse` of an oversized/malformed export | mitigate | Read + parse are wrapped in try/catch; any throw (including a parse failure on a huge/garbage file) results in a clear stderr message and `process.exit(1)` (D-07). The script is a local, user-invoked CLI — no remote attacker; the bound is accidental corruption, not adversarial load. |
| T-25-04 | Tampering | `upsertReadmeSection` overwriting README.md | mitigate | Section replacement is scoped to the `## LLM Cost Reference` heading up to the next `## ` heading or EOF (D-06); all other content is preserved by slicing around the section. Idempotency is asserted in acceptance criteria (`grep -c` equals 1 after two runs). Create-if-missing writes only a minimal scaffold, never clobbering an existing README. |
| T-25-05 | Injection / Tampering | model/source strings from untrusted JSON used as table cells & map keys | mitigate | model/source strings are treated as plain strings — used only as object keys and printed text; never passed to `eval`, `Function`, or a shell. computeCostUsd returns `unpriced` + 0 cost for unknown models rather than throwing (D-08). |
| T-25-06 | Information Disclosure | export file contains the extension's prompts | accept | The file is produced by the user's own export action and read locally; the script prints aggregate token/cost numbers, not prompt text, into the README. No new disclosure beyond the file the user already holds. |
| T-25-SC | Tampering | npm install of `tsx` | mitigate | `tsx` is [ASSUMED] (no RESEARCH audit table); Task 1 is a blocking-human legitimacy checkpoint verified against npmjs.com/package/tsx before install. Not auto-approvable. |
