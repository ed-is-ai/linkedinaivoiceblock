<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chrome.storage.local → resolve()/load() | Stored selectorRegistry is read back; candidate `value` strings are returned to consumers and passed to document.querySelector. Tampered/corrupted storage could inject a malformed or malicious selector string. |
| chrome.storage.onChanged (cross-context) | A change event in any extension context (incl. another tab) overwrites the in-memory _cache. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-02 | Tampering | migrate()/load() reading stored registry | mitigate | migrate() defensively validates stored shape (object with a targets object) before use; falls back to buildSeedRegistry() on malformed input. The seed candidate is always retained, so a corrupted adapted candidate cannot leave a target unresolvable. |
| T-22-03 | Tampering / Injection | candidate `value` used as querySelector | mitigate | querySelector treats its argument as a CSS selector string, not executable code — a malformed value throws a catchable DOMException (handled at call sites in Plan 03), it cannot execute script. No innerHTML/eval path exists. Document the constraint that only data-*/aria-*/role/semantic/URL-pattern values are valid (selectors.ts header rule). Acceptable: storage is same-extension sandboxed; no external write path exists in this phase. |
| T-22-04 | Tampering | onChanged overwriting _cache with attacker-controlled newValue | mitigate | onChanged only fires for same-extension chrome.storage.local writes; no cross-extension or web-page write access exists. newValue is the same trust level as a direct read; treated identically to load(). Multi-tab last-write-wins race documented as accepted Wave-1 limitation (Pitfall 3). |
| T-22-05 | Denial of Service | unbounded candidate list growth | mitigate | updateCandidate enforces the <=10 cap (SELECTOR-05); 30-day TTL eviction on load() bounds adapted-candidate accumulation. |
| T-22-SC | Tampering | npm installs | accept | Zero package installs this phase. |
</threat_model>
