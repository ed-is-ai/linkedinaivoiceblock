Passes `{ urn, authorId, authorName, score: mergedScore, text: postText, engineUsed: result.engineUsed }` with `.catch(() => {})`. The existing early return and all flagged/hidden branches are unchanged.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Evict oldest by seenAt instead of array.pop()**

- **Found during:** Task 1 GREEN — test (d) failed on first run
- **Issue:** The RED test pre-populated `store['unflaggedPosts']` with entries in oldest-first index order (existing-0 = oldest seenAt). The plan's `persistStoredPost`-style `pop()` evicts the last array element, which in this layout is the NEWEST entry — not the oldest. Test expected `existing-0` (oldest) to be evicted.
- **Fix:** Replaced `updated.pop()` with a linear scan to find and `splice()` out the entry with the minimum `seenAt` timestamp. This is correct regardless of what order pre-existing storage arrays are in.
