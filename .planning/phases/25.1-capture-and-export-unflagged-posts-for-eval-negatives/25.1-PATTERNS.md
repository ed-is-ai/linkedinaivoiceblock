 * LinkedIn Blocker — Post Store

/** Maximum characters of post text to store. */

> New helper: cap = **200** (D-02), reuse `POST_TEXT_MAX_CHARS = 1000` (D-05). Same import set; do NOT add any content/ or DOM imports.

**Core CRUD pattern — dedup + truncate + prepend + FIFO-evict** (`src/shared/postStore.ts` lines 37-64):
```typescript
export async function persistStoredPost(opts: {
  urn: string;
  authorId: string;
  authorName: string;
  score: number;
  text: string;
}): Promise<void> {
  const { urn, authorId, authorName, score, text } = opts;
  const { storedPosts = [] } = await storageGet(['storedPosts']);

  // Dedup: skip if this URN is already stored
  if (storedPosts.some((p: StoredPost) => p.urn === urn)) return;

  const entry: StoredPost = {
    urn,
    authorId,
    authorName,
    score,
    text: text.trim().slice(0, POST_TEXT_MAX_CHARS),
    hiddenAt: Date.now(),
  };

  // Prepend (newest first), then evict oldest if over cap
  const updated = [entry, ...(storedPosts as StoredPost[])];
  if (updated.length > POST_STORE_CAP) updated.pop();

  await storageSet({ storedPosts: updated });
}
```
> Copy this shape exactly. For `persistUnflaggedPost`: read/write the `unflaggedPosts` key, dedup by `urn` (D-03), cap at 200 (D-02), truncate text at 1000 chars (D-05). Per D-04 also record the engine + score. Per D-06 do **NOT** write any `label` field (stored UNLABELED). Timestamp field should be `seenAt` (D-07), not `hiddenAt`.

  const postsByAuthor: Record<string, StoredPost[]> = {};

## Shared Patterns

### FIFO-capped, dedup-by-URN, truncated storage write
**Source:** `src/shared/postStore.ts` lines 37-64 (`persistStoredPost`)
**Apply to:** the new `persistUnflaggedPost` helper.
- dedup: `if (arr.some(p => p.urn === urn)) return;`
- truncate: `text.trim().slice(0, 1000)`
- newest-first prepend + cap: `const updated = [entry, ...arr]; if (updated.length > CAP) updated.pop();`
- caps enforced **at write time** (per CLAUDE.md constraint), CAP = 200.

### Fire-and-forget non-blocking persistence in the detect closure
**Source:** `src/content/index.ts` line 349 (`persistStoredPost({...}).catch(() => {})`)
**Apply to:** the new capture call before L323. Never `await` in a way that blocks the hide path; trailing `.catch(() => {})`.

**Source:** `src/dashboard/index.tsx` line 87 (`chrome.storage.local.get([...])`)
**Apply to:** loading `unflaggedPosts` — add to the same `.get` array, do NOT add a second `.get` call.
