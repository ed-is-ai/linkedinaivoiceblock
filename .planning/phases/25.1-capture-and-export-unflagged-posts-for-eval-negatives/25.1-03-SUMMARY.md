# Phase 25.1 Plan 03: Add unflaggedPosts[] to buildJsonExport Summary

One-liner: Added additive `unflaggedPosts[]` top-level array to `buildJsonExport` via a defaulted third parameter, keeping all existing callers and CSV builders unchanged.

## What Was Built

Extended `buildJsonExport` in `src/dashboard/dataManagement.ts` with a third parameter `unflagged: UnflaggedPost[] = []`. The returned JSON payload now includes a `unflaggedPosts` array as a direct sibling of `flaggedAccounts` (not nested under any account). Each entry maps `urn`, `authorId`, `authorName`, `text`, `score`, and `seenAt` (converted to ISO string); `label` is forwarded via conditional spread only when present on the input (D-06 compliance — the extension never synthesises a label).

The default `[]` ensures all six existing two-arg call sites in `dataManagement.test.ts` and the dashboard caller continue to compile and pass without modification.
