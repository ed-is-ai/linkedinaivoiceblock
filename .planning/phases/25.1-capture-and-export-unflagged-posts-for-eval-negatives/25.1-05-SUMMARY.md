# Phase 25.1 Plan 05: Widen Export JSON Gate Summary

One-line gate change closing CR-01 (BLOCKER): the dashboard Export JSON button now renders whenever flagged accounts, stored posts, OR unflagged posts exist, making clean-feed eval-negative export reachable.

## What Was Built

The Export JSON button render gate in `src/dashboard/index.tsx` (line 264) was widened from `accounts.length > 0` to `accounts.length > 0 || posts.length > 0 || unflagged.length > 0`. The `unflagged` state was already loaded (line 95) and already passed to `handleExportJson` → `buildJsonExport(accounts, posts, unflagged)` (line 131); only the render gate blocked reachability. Now a user who enables capture and browses a clean feed (zero flagged accounts, zero stored posts) can click Export JSON and download a file whose top-level `unflaggedPosts[]` array is populated.
