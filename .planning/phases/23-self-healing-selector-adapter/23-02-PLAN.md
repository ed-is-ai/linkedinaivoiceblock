<objective>
Build the local, no-API heuristic re-deriver (`heuristic.ts`) and extend `SelectorRegistry` with `insertCandidate()` (prepend-winner + retain-prior + cap + seed-preservation) and a confidence-ordering helper. The heuristic analyzes the broken selector's attribute style and walks the live feed container for `data-*`/`role` analogs, returning ranked candidates that the existing validator (from 23-01) will gate.

Purpose: Deliver the first, free repair layer (ADAPT-02) and the storage-write primitive (ADAPT-07) plus confidence ordering (ADAPT-08) that both the heuristic path and the LLM path in 23-04 use to persist a winner. No DOM-write happens inside the heuristic itself — `insertCandidate` is the only new write surface and it lives in SelectorRegistry per CLAUDE.md constraint #1.
Output: `heuristic.ts` with tests; `insertCandidate` + `candidateConfidence` in selector-registry.ts with tests.
</objective>
