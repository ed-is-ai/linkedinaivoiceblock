<objective>
Add a CLI labeling helper (`npm run eval-label -- <export.json> [--auto]`) that removes the manual JSON-editing burden of adding `"label": "ai" | "human"` to export entries (D-06). Two modes: `--auto` bulk-labels flaggedPosts as `ai` and unflaggedPosts as `human` in one pass; interactive mode prompts per unlabeled post and writes back after each decision.

Purpose: Hand-editing the downloaded export JSON to label dozens of posts is slow and error-prone (a stray comma breaks the file). A small CLI that rewrites the file in-place — preserving the existing export shape — makes building a labeled eval dataset fast and safe.

Output: New `scripts/eval-label.ts` + `scripts/eval-label.test.ts`, and two new `package.json` script entries (`eval-label` and `eval-compare`).
</objective>
