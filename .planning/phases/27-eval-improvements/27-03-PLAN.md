<objective>
Add a results viewer / run-comparison CLI (`npm run eval-compare -- <results-A.json> <results-B.json> [--format markdown]`) that reads two `eval/results-*.json` files and prints a side-by-side diff of the key metrics — engine, posts scored, best-F1 threshold, precision/recall/F1/accuracy, and cost (D-07).

Purpose: Raw `results-YYYY-MM-DD.json` is hard to read and impossible to diff by eye as prompts/models/engines change. A terminal (and optional markdown) comparison table lets the developer see at a glance whether a change improved or regressed the eval, and produces a snippet pasteable into a PR description. Stays a terminal/report tool — no charting UI (D-07).

Output: New `scripts/eval-compare.ts` + `scripts/eval-compare.test.ts`. (The `eval-compare` npm script entry is added by Plan 02, which owns package.json.)
</objective>
